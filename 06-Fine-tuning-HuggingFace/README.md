# 06 - Fine-tuning & Hugging Face

Optional but powerful section.

## Topics
- Using Hugging Face Inference Endpoints with LangChain
- Fine-tuning smaller models (e.g., Gemma)
- When to fine-tune vs. when to use RAG

## Recommendation
Master RAG and agents first. Fine-tuning is useful when you need a model that consistently follows a specific style or domain format that prompting + RAG cannot achieve.
