# 05 - Advanced Projects

Apply what you have learned in complete systems.

## Projects to explore
- **CrewAI multi-agent systems** — agents with roles, tasks, and tools
- **Chat with SQL** — natural language interface to a database
- **Search engines / tool agents**
- **MathsGPT-style specialized apps**

Pick at least one and extend it.

## Tips
- Start from the working examples in the original materials.
- Add error handling, better prompts, or a simple UI.
- Trace runs with LangSmith.
